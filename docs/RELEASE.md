# Carbon Accounting Review 0.1.0 — engineering preview

The original dashboard mixed countries and aggregates in one label field. This release preserves the archived report and adds a reproducible companion audit: explicit geography scope, independent WORLD/partition checks, complete-year versus YTD safeguards and an actual-data visual report. It retains all 135,408 original rows and the original PBIX bytes.

The wheel contains dependency-free Python code and an invented MIT fixture. Install it on Python 3.11/3.12 with `python -m pip install carbon_accounting_audit-0.1.0-py3-none-any.whl`, then run `carbon-audit --demo --output demo-output`. The invented demo tests packaging only, not emissions science. The source distribution and evidence ZIP contain the attributed archived CSV, original report, processed databases, profiles, notebook and offline HTML. Open `docs/assets/carbon-report.html` from the extracted evidence ZIP. For the full real audit, use the README's three-command source quickstart.

Check each download against `SHA256SUMS`. `release-source.json` identifies the exact tagged source, code/data license scope and unverified Desktop/unit/vintage conditions. The workflow only publishes from verified main and creates an annotated owner tag on that exact main commit. Test/environment evidence and actual browser checks accompany CI artifacts; generated output hashes and source version are in the run manifest.

Real database/adaptations: Saloni Jhalani, CO2 Emissions by Sectors, Kaggle v1, ODbL 1.0 / DbCL 1.0. Code/invented fixture: MIT. The proposed DAX catalog is uninstalled and not engine-evaluated. Power BI Desktop refresh/render, primary historical release lineage, uploader-specific unit metadata and aviation/shipping allocation remain unverified. No CO2e, current-inventory, per-capita, scientific-accuracy or causal claim is made. Partial 2023 is never annualized. Source provenance and limits are documented in `docs/DATA.md` and `docs/methodology.md`.

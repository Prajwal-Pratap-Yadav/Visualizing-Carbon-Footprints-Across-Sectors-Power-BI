# Changelog

All notable changes are documented here. Versions follow semantic versioning.

## [0.1.0] - 2026-10-07

### Added

- Typed, dependency-free carbon accounting audit with explicit geography keys, bounded decimals, source checksums and strict calendar/sector validation.
- Retained all-label, WORLD and nonoverlapping-region exports; independent spatial residuals and complete-year/matched-YTD analytics.
- Real-data visual review, offline interactive report, executed ordinary-Python notebook, generated dictionary and descriptive insights.
- Read-only original model catalog/cache checks, proposed uninstalled DAX templates and source/units/license methodology.
- Hash-locked Python tools, optional browser QA, meaningful tests, CPU CI, secret/advisory scans and attributed release packaging.

### Preserved

- Original CSV, PBIX, historical README and MIT notice byte-for-byte; granular existing Git history.

### Known limitations

- Engineering preview: Desktop refresh/render and DAX outputs are not validated. Original primary release lineage, uploader-specific unit metadata and shipping/aviation allocation remain qualified. Arithmetic reconciliation does not certify emissions accuracy. No population/per-capita result or annualized 2023 estimate is supplied.
